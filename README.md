# 📊 Stock Analyzer Dashboard

An interactive, all-in-one Streamlit web application for analyzing stock performance, conducting technical and fundamental analysis, identifying chart patterns, and managing a simulated investment portfolio.

---

## 🚀 Features

### 1. 📈 Technical Charts
- Interactive candlestick charts with zoom and pan
- Indicators: RSI (Relative Strength Index), SMA (Simple Moving Average), EMA (Exponential Moving Average)
- Auto-generated **Buy/Hold/Sell recommendation** based on RSI + trend analysis
- RSI plotted separately for better visualization

### 2. 🧮 Fundamental Analysis
- Key financial metrics (P/E, EPS, ROE, Revenue, Profit Margin, etc.)
- Company profile: industry, sector, employee count, website, etc.

### 3. 📐 Pattern Recognition
- Automatic detection of common candlestick patterns:
  - Bullish/Bearish Engulfing
  - Doji
  - Hammer
  - Shooting Star

### 4. 📂 Portfolio Tracker
- Add simulated trades (buy/sell)
- View current holdings, net investment, portfolio value, and PnL
- **Download portfolio to CSV** with a single click
